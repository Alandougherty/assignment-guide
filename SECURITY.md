# Reporting a security concern

Do not post course keys, student identities, coursework, private chat exports or
operational details in public GitHub issues. For a concern involving course access
or coursework records, contact your teaching team through the course's private
support channel. Ask them to coordinate with the service operator and maintainer.

Use a minimal synthetic example when describing a problem. Do not test against
other students, real coursework or a live service without explicit authorisation.
A dedicated public maintainer security contact is not yet designated.
