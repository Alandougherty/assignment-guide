# Feedback and reporting

This repository holds the usage documentation and the published releases for
Assignment Guide. The extension's source code is not published here, and the
project is supplied under restricted-use terms rather than an open-source licence.
Reuse, modification and redistribution require permission from the rights holder.
There is no standing contribution grant in this repository and code contributions
are not accepted.

Report product problems using a small synthetic example. Do not include assignment
solutions, student identities, course keys or unredacted coursework logs. Anything
involving your own course access or your coursework records goes to your teaching
team through the course's private support channel rather than a public issue.

## What the releases contain

The extension ID is `alandougherty.assignment-guide`. Existing command IDs remain
compatible with current installations. Student connections use the approved service
address and a personal course key. Neither this repository nor the published
releases contain the course service, its operating configuration or its credentials.

Uninstall any older tutor extension before installing this one, or duplicate
command registrations can result. Migration from prototype extension IDs has been
removed, so an older installation's records are neither imported nor deleted, and a
fresh install needs a teacher-supplied personal course key. Existing state for the
current extension ID is retained unless the operator explicitly resets it.

Assignment content comes from the course service, not from a catalogue built into
the extension. Production identity, recording policy, retention and cohort capacity
are agreed with the course operator.

Each release includes generated THIRD-PARTY-NOTICES.txt with complete dependency
notices, including code incorporated in the Markdown bundle. Third-party components
remain under their own licences.
